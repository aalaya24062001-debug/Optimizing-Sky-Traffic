# Flight Delay Prediction Project

An end-to-end data analysis and machine learning project focused on predicting commercial flight delays. This solo project covers the full data science lifecycle, from data processing to advanced visualization and modeling.

## Key Contributions & Technical Highlights
* **Data Processing & Analytics:** Built clean data pipelines using Python within an Anaconda environment.
* **Predictive Modeling:** Implemented classification models to accurately evaluate and predict delay probabilities.
* **Advanced Features:** Utilized the **ETA method** for optimized temporal modeling and timeline alignment from 2020 - 2026.
* **Data Visualization:** Generated interactive and static graphical representations directly inside Jupyter Notebook to present descriptive and predictive insights.

## Tech Stack
* **Language:** Python
* **Environment:** Jupyter Notebook / Anaconda
* **Key Libraries:** Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
